# 📈 LSTM Stock Price Predictor

A machine learning project that predicts stock closing prices using LSTM (Long Short-Term Memory) neural networks. It includes a clean and interactive Streamlit web app for forecasting future stock prices based on historical data with technical indicators like RSI and MA20.

## 🧠 Project Overview

This project uses historical stock data to train an LSTM model capable of predicting future stock prices. Users can:
- Search and select stocks using ticker symbols.
- View actual vs predicted prices on historical data.
- Forecast future stock prices (3 to 30 days).
- Explore recent RSI and moving average trends.

## 📋 Features

- Yahoo Finance integration for real-time stock data.
- LSTM model trained with technical indicators (RSI, MA20).
- Forecast future prices dynamically.
- Clean UI built with Streamlit.
- Downloadable forecasts and visualizations.

## 🔧 Tools & Libraries

- Python
- TensorFlow / Keras
- Streamlit
- yFinance
- Scikit-learn
- Matplotlib & Pandas
